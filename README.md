# GDriveSync

Personal Mac menu-bar app that syncs my own Google Drive with a local folder. For private use only.

## Privacy
The app works only with my own Google account. It reads and changes files in my Google Drive
solely to synchronize them with a folder on my Mac. No data is sent to the developer
or to any third party; files and access tokens stay on my computer.
